# Jouni Jokelainen — CV

A small, bilingual CV website built with HTML, CSS, and vanilla JavaScript. It has no build step or package dependencies. Archivo and Space Grotesk are loaded from Google Fonts, with system font fallbacks.

## Run locally

Open `index.html` in a browser. The language controls switch between Finnish and English, and the theme control toggles dark mode. The initial theme follows the device preference.

## Publish with GitHub Pages

1. Create a GitHub repository and add these files to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.
5. Once the deployment finishes, open the Pages URL shown in the repository settings.

The site uses relative asset paths, so it works both from a user site and a repository project site.
